The scripts are mostly written in a way that they can be executed on their own. For R you will need to start Rstudio and load the fucntion in the script numbered 000 and whatever script you want to execute. You might also need to install some packages.
Python script should run fully automatically.

For R, I work in Rstudio and open the sub-scripts I need to work on something. That means usually I have one script open and one script where I write general functions. The latter is thus also formed into the start of its own package. 

For python I usually write the script and then execute it. The reason for this is that in order to write more complicated processes I need my python scripts to be fully automatic, but I also want each script to be usable in isolation if somebody want to use my work. That is why right now I am reusing a lot of code in each script.
