## Overview


The purpose of this repository is to make the calculations and statistics I do for different TCGs publicly available. I write about these statistics to get a deeper understanding and also explore the vast data that exists in TCGs.

An example is looking at statistics on lands in hand with different land counts in the deck:

## Structure

The Repository is structured into Plots, Scripts, Data, and Other results.

Scripts are numbered according to a logical sequence on how to explore the data generally. Executing the scripts should make it possible to easily generate the same data and adjust for your own projects. 

Thus, I also try to make simpler scripts independently usable. But some of the processes I want to automate or explore require more dependencies. For example, since I make my stuff also available over Google Docs, I have some scripts here to help with this. To do this, I wrote a class to make it easier to deal with what the Google Docs API provides. To use these scripts, you also need the class file. 

Plots are also named by the chapter where they occur in my writing projects. If you come from one of these projects over here, that should make it easy to find any plot you are interested in. 

As I write more, I will also build and try out more.
